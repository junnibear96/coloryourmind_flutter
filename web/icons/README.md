# Web Icons Placeholder

This directory should contain the following icon files for the web app:

- Icon-192.png - 192x192 PNG icon
- Icon-512.png - 512x512 PNG icon  
- Icon-maskable-192.png - 192x192 maskable PNG icon
- Icon-maskable-512.png - 512x512 maskable PNG icon
- favicon.png - Favicon for the web app

To generate these icons, you can:
1. Use a tool like https://icon.kitchen/
2. Use Flutter's flutter_launcher_icons package
3. Create them manually using an image editor

For now, the app will work without these icons, but they should be added for a complete PWA experience.
