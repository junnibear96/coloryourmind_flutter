# iOS Assets Placeholder

This directory should contain iOS app icons and launch screens:

## App Icons
iOS requires app icons in various sizes. Use an Asset Catalog (Assets.xcassets) with:
- AppIcon.appiconset containing icons from 20x20 to 1024x1024

## Launch Screen
- LaunchImage.imageset or a LaunchScreen.storyboard

To generate these assets, you can:
1. Use Xcode's Asset Catalog
2. Use Flutter's flutter_launcher_icons package
3. Create them manually

For now, the app will use default assets, but custom icons and launch screens should be added.
