# Android Icons Placeholder

This directory should contain the Android launcher icons in various densities:

- mipmap-mdpi/ic_launcher.png - 48x48
- mipmap-hdpi/ic_launcher.png - 72x72
- mipmap-xhdpi/ic_launcher.png - 96x96
- mipmap-xxhdpi/ic_launcher.png - 144x144
- mipmap-xxxhdpi/ic_launcher.png - 192x192

To generate these icons, you can:
1. Use Android Studio's Image Asset Studio
2. Use Flutter's flutter_launcher_icons package
3. Create them manually

For now, the app will use the default Flutter icon, but custom icons should be added.
